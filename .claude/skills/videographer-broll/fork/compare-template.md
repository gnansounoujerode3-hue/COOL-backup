# Compare template

This is the template the orchestrator copies into
`${VIDEO_JOBS_DIR}/<brief_id>/COMPARE.md` after fork mode finishes
running. Fill placeholders from the brief, `QA.json`, and each fork's
`<tool>/notes.md`.

Rules for the orchestrator filling this in:

- One row per output mp4 (not per tool, in case a tool produced multiple).
- "Duration" is `m:ss`, derived from `out_NN.qa.json -> duration_sec`.
- "LUFS" is the integrated LUFS rounded to one decimal.
- "True Peak" comes from the loudness gate in dBTP.
- "Face-safe" shows the face-safety verdict; if WARN or FAIL, append the
  earliest violation timestamp from `out_NN.face_safety.json` as `@ m:ss`.
- "Overall" is the worst verdict across all gates for that output.
- "Notes" is the first non-empty line from `<tool>/notes.md`.
- The recommendation paragraph is generated by the orchestrator: one
  paragraph, peer tone, references concrete QA evidence, no em dashes, no
  filler like "bottom line" or "in conclusion".
