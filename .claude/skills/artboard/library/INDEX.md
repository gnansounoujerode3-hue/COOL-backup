# Composition library: index

One line per creative measured. Newest last. Read this before measuring anything;
append to it after. Full entries live beside this file as `<slug>.md`.

**Every entry is callable by name.** "Recut the Systo Own/Operate ad for stories"
resolves through the *Call it* column below — match case-insensitively against the
name, the slug, or any alias in the entry — then runs from that entry's measured
system rather than re-opening the source.

**What belongs here:** composition *system* facts. Grid, ratios, type scale,
sampled palettes, element inventories with measured boxes and tilts, reframing
rules, which ratios were produced and what nearly broke.

**What does not:** assets, imagery, logos, body copy. Those stay with the job that
needed them. The library is knowledge, not content.

**Fidelity** is declared per entry and never promoted without re-measuring:
`spec` licenses a recut without re-opening the source; `partial` saves most of a
re-measure; `signature-only` is a vocabulary; `none` is a placeholder.

## Reading a row

*Native* is the source ratio, which is the layout the composition was actually
designed for. Recutting away from it is a re-layout, not a crop — the further from
native, the more the layout has to change.

*Class* decides the treatment before anything else. A **layout** creative has
elements arranged in a frame, so a ratio change moves them and this skill applies
in full. A **subject** creative is one thing on a background with no arrangement to
preserve, so a ratio change is a reframe or an outpaint, and most of the skill does
not apply. Getting this wrong is the most expensive mistake available: re-laying
out a packshot is meaningless, and reframing a layout destroys it.

An **original** has no source at all. It was authored, so there is nothing to
measure and nothing to be faithful to; the entry records the *system* that was
built and the techniques that made it work. These are the entries §Generate
composes from, and the ones to read before starting anything from scratch.

*Fidelity* tells you whether you can work from the entry alone. Only `spec` means
yes, and even then the entry supplies measurements, never pixels: the source file
still has to provide those.

*Notable* is the thing that would have cost an hour if nobody had written it down.
