Five gates, minutes each, before the code

Studios put days between these stages because a human has to look and respond. An agent does not need days. It needs to actually stop and do the gate's job instead of skipping it because nothing is forcing a pause.

Converged from two independent sources: a working agency's documented process and a motion design educator's project guide. The storyboard gate is the last stage where significant changes do not create major delays.

The same shape, adapted to agent speed

GATE 1

Concept statement

replaces treatment

One paragraph before any code. The one dominant idea, what the viewer should feel, what carries the argument. Name 2 to 3 directions and pick one with a stated reason.

GATE 2

Shot list

replaces storyboard

One line per beat. The cheapest check and the one most worth never skipping. Read it back and ask whether every beat needs to look different from its neighbours, and does.

GATE 3

Style-frame check

replaces style frames

Render ONE static frame, the busiest beat or frame 0, and look at it as a still. Catch a wrong composition before spending effort animating it.

GATE 4

Rough timing pass

replaces animatic

Structure first: beats, cuts, rough durations, no polish. A wrong structure throws away finished polish along with it.

GATE 5

Self-critique

replaces final review

Does every element earn its place? Does visual weight match significance? Are transitions designed or accidental? If an answer is uncomfortable, the gate is working.

The failure this exists to prevent

A stat video passed every technical check and still needed a from-scratch rebuild once a human actually looked at it. The first attempt shipped:

  • Four visually identical scenes
  • A decorative field with no reason to be there
  • Zero variation in weight or pacing

All of it was visible in a shot list before a single line of CSS. "5 scenes, identical layout, identical motion trick, identical colour, no camera, no transition" reads as a warning even as a sentence.
